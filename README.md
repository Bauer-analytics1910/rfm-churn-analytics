# rfm-churn-analytics
Análise de evasão (Churn) e retenção de clientes via metodologia RFM. Projeto end-to-end combinando Engenharia de Dados (ETL no Databricks com Apache Spark e SQL) e inteligência de negócios através de um painel executivo (OBT) no Power BI. Foco estratégico em operações comerciais.
